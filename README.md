# 🌍 Countries Web Scraping Project

A Python web scraping project that collects country information, including country names, capitals, population, and area, and saves the data in CSV and JSON formats.

## Features

- Scrapes country information
- Collects country names
- Extracts capitals
- Collects population data
- Extracts country area in square kilometers
- Saves data in CSV and JSON formats
- Structured dataset for analysis

## Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas

## Project Structure

```text
Countries-Web-Scraping-Project/
├── data/
│   ├── countries_data.csv
│   └── countries_data.json
├── countries_scraping.py
└── README.md
```

## How to Run

Install libraries:

```bash
python -m pip install requests beautifulsoup4 pandas
```

Run the scraper:

```bash
python countries_scraping.py
```
